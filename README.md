# Text analysis pipeline

Программа обрабатывает текст с помощью языковой модели и возвращает JSON:
`summary`, `category`, `intent`, `sentiment`, `key_points`, `final_answer`
и `self_check` с результатом проверки содержания.

Реализованы этапы 1–5. Обработка состоит из пяти последовательных шагов:

1. Модель извлекает краткое содержание и три ключевые мысли.
2. По исходному тексту и извлечённому смыслу модель определяет категорию,
   цель пользователя и настроение.
3. Python собирает и проверяет структурированные поля из двух результатов.
4. Модель получает эти поля, исходный текст и инструкции выбранной категории,
   затем пишет итоговый ответ.
5. Отдельный вызов модели сравнивает результат с исходным текстом: ищет
   противоречия и потерянные важные детали.

Все ответы модели проходят проверку JSON и Pydantic. Содержание ограничено
250 символами, цель — 160, итоговый ответ — 400; ключевых мыслей ровно три.
В логах видны номера шагов, выбранная категория, цель и итог проверки.

| Категория | Инструкции ответа |
|---|---|
| `support` | Короткие нумерованные шаги диагностики |
| `feedback` | Признание конкретного отзыва и конструктивная реакция |
| `complaint` | Сочувствие и предложение пути решения проблемы |
| `sales` | Связь потребностей с известными возможностями и следующий шаг |
| `general_question` | Прямой ответ или короткий план действий |

Категория описывает тип обращения, `intent` — конкретную цель автора.
Критика без требования устранить нарушение относится к `feedback`;
жалоба с требованием возврата или разбирательства — к `complaint`.
Настроение: `positive`, `neutral`, `negative`.

## Структура

- `main.py` — запуск, фильтрация и вывод результата в JSON.
- `llm_client.py` — вызовы API модели.
- `prompts.py` — инструкции четырёх обращений к модели.
- `pipeline.py` — пять последовательных шагов и обработка ошибок.
- `schemas.py` — схемы промежуточных данных и итогового результата.
- `compare_prompts.py` — сравнение вариантов извлечения смысла.
- `sample_inputs/` — десять текстов и ожидаемые категории для проверки.
- `tests/` — проверки цепочки без сетевых запросов.
- `docs/prompts.md` — варианты промптов и статус их выбора.

## Запуск

Нужны Python 3.10+ и ключ API:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Впишите ключ в `.env` вместо `your_api_key_here`. Файл `.env` исключён из Git.
По умолчанию используется `gpt-4.1-mini`; модель задаётся через `OPENAI_MODEL`.
Для сервиса с поддержкой Responses API и JSON-схемы задайте `OPENAI_BASE_URL`.

```bash
python main.py --demo
python main.py --demo --output output/demo.json
python main.py --text "Помоги составить план встречи"
python main.py --file /path/to/input.txt
python main.py --demo --prompt-variant baseline
python main.py --demo --category feedback --sentiment negative
```

Программа печатает массив JSON. Один полный цикл делает четыре вызова модели;
`--demo` обрабатывает десять текстов — 40 вызовов при успешных шагах.
При ошибке API или невалидном ответе элемент получает поле `error`.
Если проверка содержания найдёт проблему, результат сохраняется вместе
с `self_check.passed: false`, `contradictions` и `missing_details`.
Программа продолжает обработку остальных текстов и возвращает код 1 при
ошибках или непройденных проверках. Такие результаты видны и при фильтрации.
Проверка моделью может ошибаться и не гарантирует достоверность ответа.

Сопоставьте `category` с `sample_inputs/expected_categories.json` и просмотрите
ответы и замечания проверки. Ожидаемые категории не передаются модели.
Варианты первого шага: `baseline`, `explicit` (по умолчанию), `example`.
Необязательное сравнение: `python compare_prompts.py` — до 120 вызовов,
три варианта на десяти текстах. `--repeats` задаёт повторы; `--output`
сохраняет отчёт. Файлы `output/` исключены из Git.

## Проверка

```bash
python -m unittest discover -s tests -v
```

Тесты проверяют полный цикл на десяти текстах с заданными ответами,
передачу данных между шагами, выбор инструкций, ошибки и замечания проверки.
Точность классификации и качество реальных ответов требуют запуска с ключом API.
