# Text analysis pipeline

Программа обрабатывает текст с помощью языковой модели и возвращает краткое
содержание, три ключевые мысли и полезный ответ в JSON.

Выполнены этапы 1–2 по реализации: клиент API, обработка текста, три варианта
промпта и команда их сравнения. Схема ограничивает содержание 250 символами,
ответ — 400; ключевых мыслей должно быть ровно три. Результаты проверяются
перед выводом. Для сравнения качества промптов нужен запуск с ключом API.

## Структура

- `main.py` — запуск из командной строки и вывод результата в JSON.
- `llm_client.py` — вызов API модели.
- `prompts.py` — инструкции модели.
- `pipeline.py` — соединяет этапы и проверяет ошибки.
- `schemas.py` — схема результата.
- `compare_prompts.py` — сравнение вариантов на одинаковых входах.
- `sample_inputs/` — три демонстрационных текста.
- `tests/` — проверки обработки ответа модели без сетевых запросов.
- `docs/prompts.md` — варианты промптов и статус их выбора.

## Запуск

Нужны Python 3.10+ и ключ API. Создайте окружение и установите зависимости:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Впишите ключ в `.env` вместо `your_api_key_here`. Файл `.env` исключён из Git.
По умолчанию используется `gpt-4.1-mini`; при необходимости измените
`OPENAI_MODEL`. Для совместимого API задайте `OPENAI_BASE_URL`.

```bash
python main.py --demo
python main.py --demo --output output/demo.json
python main.py --text "Помоги составить план встречи"
python main.py --file /path/to/input.txt
python main.py --demo --prompt-variant baseline
python compare_prompts.py --repeats 3 --output output/prompt_comparison.json
```

Программа печатает массив JSON. Для каждого текста в нём есть `summary`,
`key_points` и `helpful_response`. При ошибке API или невалидном ответе модели
элемент получает поле `error`, а программа завершает работу с кодом 1. В журнале
отмечены основные этапы без исходных текстов и ключа API.

Доступны варианты `baseline`, `explicit` (по умолчанию), `example`.
Сравнение с тремя повторами выполняет 27 запросов: три варианта на трёх текстах.
Отчёт содержит исходные тексты, формулировки промптов, ответы и статистику
соблюдения формата. Файлы `output/` исключены из Git.
